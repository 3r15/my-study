# 정보처리산업기사 필기 학습 사이트

제공한 기출문제 PDF와 2026 핵심요약집 PDF를 파싱해서 만든 정적 학습 사이트입니다.
서버 없이 `index.html`만 열면 동작하고, 그대로 GitHub Pages에 올릴 수 있습니다.

## 구성

```
study-site/
├─ index.html            앱 전체 (SPA, 외부 라이브러리 없음)
├─ data/
│  ├─ index.json         회차 목록 + 단원 정의
│  ├─ exam-2022-1.json   회차별 문제은행 (60문항)
│  │  … exam-2025-3.json (총 12개 파일 / 720문항)
│  ├─ summary.json       핵심요약집 193항목
│  └─ glossary.json      용어사전 127개
└─ img/                  문제 그림·선택지 그림·요약집 원본 이미지 (294개)
```

## 담고 있는 것

| 항목 | 수량 | 출처 |
|---|---|---|
| 기출문제 | 720문항 (2022·2023·2024·2025년 각 1~3회) | 기출문제 PDF 12개 |
| 표가 포함된 문항 | 22 | 구조화된 grid로 저장 |
| 코드가 포함된 문항 | 61 | 들여쓰기 유지 |
| 지문 그림 | 15 (트리·그래프·다이얼로그) | PDF 벡터/이미지 영역 크롭 |
| 선택지가 그림인 문항 | 7 (E-R 기호, frameset, 결과 테이블) | 선택지 영역 통째 크롭 |
| 핵심요약 | 193항목 (+ 원본 페이지 이미지) | 2026 핵심요약집 |

기출은 전부 **정답이 매핑**되어 있고(720/720), 각 문항에 **과목·단원·관련 요약 항목**이 자동 태깅되어 있습니다.

> 2022년부터 시험이 3과목 60문항 체제로 개편되어, 현행 출제범위와 일치하는 2022년 이후만 담았습니다.
> 2005~2021년 구 체계 기출은 나중에 추가할 수 있습니다 (아래 "확장" 참고).

## 화면

### 1. 기출문제
- **회차별** — 12회차, 이어풀기 지원
- **과목별 / 단원별 / 랜덤 / 틀린 문제만 / 취약 개념 집중**
- 표·코드·그림·선택지 그림 모두 렌더링
- 채점 즉시 정답 + **내가 고른 선택지가 어떤 개념인지** 표시 + 관련 요약 링크 + 메모

### 2. 핵심요약 · 용어사전
- 과목 → 단원 → 항목 트리, 전문 검색
- 각 항목: 텍스트 요약 + 요약집 **원본 이미지 토글** (표·그림이 있는 항목은 원본이 기본 열림)
- 학습 완료 체크, 항목별 메모
- 항목 ↔ 관련 기출문제 양방향 링크

### 3. 오답분석 · 문제생성
- 선택지 기반 오개념 분석 (아래 상세)
- 취약 개념 랭킹 / 단원별 정답률
- 취약 개념 기출 재출제 / 요약집 기반 문제 자동 생성 / AI 프롬프트 내보내기

## 오답 분석이 동작하는 방식

빌드 단계에서 **모든 선택지 하나하나에** 관련 요약 항목을 붙여 뒀습니다 (`options[].refs`).

```json
{
  "no": 8, "answer": 1, "refs": [54, 52, 53],
  "options": [
    {"no": 1, "text": "하나의 객체를 생성하면 …", "refs": [54, 47]},
    {"no": 2, "text": "원본 객체를 복제하는 …",   "refs": [53]},
    {"no": 3, "text": "여러 객체를 가진 복합 …",  "refs": [55]},
    {"no": 4, "text": "수많은 객체들 간의 …",     "refs": [52]}
  ]
}
```

문제를 틀리면 이렇게 점수가 쌓입니다.

| 신호 | 의미 | 가중치 |
|---|---|---|
| 내가 고른 오답의 `refs` | 이 개념을 **옳다고 착각**했다 | **+3** |
| 정답 선택지의 `refs` | 이 개념을 **몰랐다** | +2 |
| 문항 주제 `refs[0]` | 이 주제가 약하다 | +2 |
| 정답을 맞힌 문항의 `refs` | 회복 | −1 |
| "모르겠음" 누름 | 주제 전체가 약함 | +2 |

예를 들어 싱글톤 문제에서 ②(프로토타입 설명)를 고르면
→ *"053 생성 패턴 - 프로토타입"* 에 +3, *"054 싱글톤"* 에 +2가 쌓입니다.
즉 **"싱글톤을 몰라서"가 아니라 "프로토타입과 싱글톤을 헷갈려서" 틀렸다**는 게 기록됩니다.

오답분석 화면의 「선택지로 본 오개념」은 이 기록을 개념별로 묶어서 보여줍니다.

## 문제 생성

**A. 기출 재출제** — 취약 점수 상위 12개 개념과 연결된 기출을, 미풀이 > 틀림 > 맞힘 순으로 정렬해 출제

**B. 요약집 기반 자동 생성** (완전 오프라인, 클라이언트에서 생성)
- `notin` — "다음 중 「XXX」에 해당하지 않는 것은?" : 해당 항목 불릿 3개 + 다른 항목 불릿 1개
- `define` — "다음 설명에 해당하는 것은?" : 용어 정의 → 용어 맞히기
- `match` — "「XXX」에 대한 설명으로 옳은 것은?" : 용어 → 정의 맞히기

오답 보기는 **같은 단원**에서 우선 뽑아 난이도를 맞추고, 정답 보기와 머리말이 겹치면 제외해 모호한 문제를 방지합니다. 예제 풀이 과정·숫자 나열 불릿은 재료에서 제외합니다.
(생성 600문항 자동 검증: 보기 4개·중복 없음·정답 범위 이상 0건)

**C. AI 연동** — 「프롬프트 복사」를 누르면 내 취약 개념 + 메모 + 최근 오답이 담긴 프롬프트가 복사됩니다.
Claude/ChatGPT에 붙여넣고 받은 JSON을 「생성 JSON 불러오기」로 그대로 풀 수 있습니다.

```json
[{"q":"문제 지문","code":"코드/표(선택)","options":["…","…","…","…"],
  "answer":2,"why":"해설","misread":["①을 고른 이유","②…","③…","④…"],"topic":"개념명"}]
```

## 데이터 저장

모든 학습 기록은 브라우저 `localStorage`(키 `jbsg_v2`)에만 저장됩니다.

```js
{ answers:{qid:{sel,ok,t,exam,no,sub,unit}},  // 문항별 응답
  weak:{secNo: score},                        // 취약 개념 점수
  notes:{qid: "메모"}, secNotes:{secNo: "메모"},
  secRead:{secNo:1}, gen:[…], unknown:[qid] }
```

기기를 옮기거나 초기화하기 전에 **⚙ → 백업 내보내기**로 JSON을 저장하세요.

## GitHub Pages 배포

```bash
cd study-site
git init && git add . && git commit -m "study site"
git remote add origin https://github.com/3r15/my-study.git
git branch -M main && git push -f origin main
```
Settings → Pages → Source: `main` / `/ (root)` → `https://3r15.github.io/my-study/`

로컬 확인은 `python -m http.server 8000` 후 `http://localhost:8000`

> ⚠️ **`index.html`을 더블클릭해서 열면 동작하지 않습니다.**
> `file://`에서는 브라우저 보안 정책상 `fetch`로 `data/*.json`을 읽을 수 없습니다.
> (이 경우 화면에 안내 메시지가 뜹니다.)

## 로딩 속도

| 구간 | 크기 | 시간 |
|---|---|---|
| 초기 전송 (index.html + index.json + summary.json) | 143KB → **gzip 49KB** | — |
| JS 부팅(파싱 + 첫 화면) | | **20ms** |
| 화면 렌더 (가장 무거운 요약 193항목) | | 22ms |
| 회차 12개 프리페치 (백그라운드) | 438KB | 65ms |

- `glossary.json`은 용어사전·문제생성 탭에 들어갈 때만 받습니다.
- 회차 데이터는 첫 화면을 그린 뒤 `requestIdleCallback`으로 미리 받아 둡니다.
- `sw.js`(서비스 워커)가 캐시하므로 **두 번째 방문부터는 네트워크 없이 즉시** 뜨고, 오프라인에서도 동작합니다.
- 데이터를 바꾸면 `sw.js`의 `const V = 'jbsg-v1'` 값을 올려 주세요. 안 그러면 옛 캐시가 남습니다.
- `manifest.webmanifest`가 있어 모바일에서 "홈 화면에 추가"하면 앱처럼 실행됩니다.

## 확장

- **구 체계 기출 추가** — `data/exam-YYYY-N.json`을 같은 스키마로 추가하고 `data/index.json`의 `exams` 배열에 항목을 넣으면 됩니다.
- **단원 재정의** — `data/index.json`의 `units`(과목·이름·요약항목 범위)만 고치면 전 화면에 반영됩니다.
- **해설 추가** — 2024년 PDF에는 해설이 있습니다. 문항 JSON에 `"explain": "…"` 필드를 넣고 `fbHtml()`에서 출력하도록 한 줄 추가하면 됩니다.
