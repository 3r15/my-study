# 정보처리산업기사 필기 · 실기 학습 사이트

제공한 기출문제 PDF와 2026 핵심요약집 PDF를 파싱해서 만든 정적 학습 사이트입니다.
헤더의 **필기 / 실기** 토글로 두 모드를 오갑니다.
서버 없이 `index.html`만 열면 동작하고, 그대로 GitHub Pages에 올릴 수 있습니다.

## 구성

```
study-site/
├─ index.html            앱 전체 (SPA, 외부 라이브러리 없음)
├─ data/
│  ├─ index.json         [필기] 회차 목록 + 단원 정의
│  ├─ exam-2022-1.json   [필기] 회차별 문제은행 (60문항)
│  │  … exam-2025-3.json        (총 12개 파일 / 720문항)
│  ├─ summary.json       [필기] 핵심요약집 193항목
│  ├─ glossary.json      [필기] 용어사전 127개
│  ├─ new-concepts.json  [필기] 요약집 미수록 신출 개념
│  ├─ mock-bank.json     [필기] 직접 제작 모의고사 문항 66개
│  ├─ memo-cards.json    [필기] 자주 틀린 개념 암기 카드 34장
│  ├─ prac-exam.json     [실기] 기출 231문항 (12회차)
│  ├─ prac-index.json    [실기] 회차·유형·언어·개념 집계
│  └─ prac-note.json     [실기] 기출 분석 학습노트 33개
└─ img/                  문제 그림·선택지 그림·요약집 원본 이미지 (294개)
```

## 화면 — 필기

### 1. 기출문제
- **회차별** — 12회차, 이어풀기 지원
- **과목별 / 단원별 / 랜덤 / 틀린 문제만 / 취약 개념 집중**
- 표·코드·그림·선택지 그림 모두 렌더링
- 채점 즉시 정답 + **내가 고른 선택지가 어떤 개념인지** 표시 + 관련 요약 링크 + 메모

### 2. 핵심요약 · 용어사전
- 과목 → 단원 → 항목 트리, 전문 검색
- 각 항목: 텍스트 요약 + 요약집 **원본 이미지 토글** (표·그림이 있는 항목은 원본이 기본 열림)
- 학습 완료 체크, 항목별 메모
- 항목 ↔ 관련 기출문제 양방향 링크

### 3. 오답분석 · 문제생성
- 선택지 기반 오개념 분석 (아래 상세)
- 취약 개념 랭킹 / 단원별 정답률
- 취약 개념 기출 재출제 / 요약집 기반 문제 자동 생성 / AI 프롬프트 내보내기

### 4. 직접 제작 모의고사 (60문항)
실제 시험과 같은 **3과목 × 20문항**으로 조립합니다. 세 갈래를 섞습니다.

| 갈래 | 재료 | 뽑는 방식 |
|---|---|---|
| **A 빈출 기출** | 12회차 기출 720문항 | 반복 출제된 상위 45개 개념에 걸린 문항 |
| **B 신출 유형** | 2024-1 ~ 2025-3 기출 | 2024년 이후에만 등장한 개념의 문항, 과목당 최대 4개 |
| **C 직접 제작** | `mock-bank.json` 66문항 | **내 취약 개념 점수가 높은 것부터** 과목당 8개 |

- 같은 기출이 A와 B에 겹치지 않게 하고, **아직 안 푼 문항을 먼저** 넣습니다.
- 2과목은 2024~2025 신출 개념이 거의 없어 B가 1~2문항에 그치고, 그만큼 A가 채웁니다. 총합은 항상 60문항입니다.
- 취약 개념 기록이 없으면 C는 **출제 빈도가 높은 개념** 위주로 뽑습니다.
- 조립한 세트는 `S.mock`에 남아 브라우저를 닫아도 이어서 풀 수 있습니다.
- 채점은 실제 기준(**전체 60점 이상 + 과목별 40점 이상**)으로 하고 과락을 표시합니다.
  결과에서 과목별·갈래별 정답률과 틀린 문항 목록을 보여 주며, 오답은 취약 개념 점수에 반영됩니다.

제작 문항은 보기마다 **짚어보기**를 달았습니다. "옳지 않은 것은?" 유형은 정답 보기에
왜 그 설명이 틀렸는지를, 나머지 유형은 각 오답 보기를 고른 사람이 무엇을 착각한 것인지를 적었습니다.

### 5. 개념 암기 카드 (34장)
내 오답에서 **자주 걸린 개념**을 골라 시각 자료와 예시로 정리한 카드입니다.
학습노트 탭이나 홈에서 들어갑니다.

카드를 고르는 기준은 "많이 나온 개념"이 아니라 **"오답 선택지로 많이 쓰인 개념"** 입니다.
720문항의 오답 선택지 `refs`를 집계하면 실제로 사람들이 헷갈리는 지점이 드러납니다
(사용자 정의 함수 125회, DB 설계 순서 79회, Select문 63회, 릴레이션의 특징 62회 …).

| 시각 자료 | 쓰이는 곳 |
|---|---|
| `table` | 비교표 — 기법·용어·분류 대조 |
| `scale` | 강약 눈금 — 결합도 6단계, 응집도 7단계, 연산자 우선순위 |
| `layers` | 계층 스택 — OSI 7계층, TCP/IP 4계층, 교착상태 4조건 |
| `steps` | 순서 흐름 — 설계 5단계, 정규화, SELECT 절 순서 |
| `calc` | 계산 과정 — 스케줄링·페이지 교체·디스크 이동·수식 변환 |
| `code` | 코드 예시 + 출력 |
| `tree` | SVG 트리 그림 — 이진 트리 운행법 |
| `note` | 함정 경고 |

카드마다 `핵심 한 줄` + 시각 자료 + `헷갈리는 짝` + `외우기`(암기법)로 구성됩니다.
취약 개념 점수 순으로 정렬되고, 그 개념에서 **몇 번 틀렸는지**가 함께 표시됩니다.
카드가 없는 취약 개념은 요약집 원문으로 넘어가는 링크로 대신 채웁니다.

**「⤓ HTML로 내보내기」** 를 누르면 스타일까지 파일 하나에 담은
**자체 완결 HTML**(`내_취약개념_정리_YYYY-MM-DD.html`)을 내려받습니다.
외부 요청이 전혀 없어 오프라인에서도 열리고, 인쇄하면 카드가 잘리지 않게 페이지가 나뉩니다.

### 6. 시험 전 최종 오답노트 (마크다운 내보내기)
내가 틀린 기출을 **개념별로 묶어** 마크다운 문서로 내보냅니다.
오답분석 탭이나 홈에서 들어갑니다.

- **범위** — `2024~2025년`(기본) / `2025년만` / `전체 12회차`, 과목별 필터
- **문서 구성** — 한눈에 보는 과목별 정답률 표 → 가장 많이 걸린 개념 10개
  → **시험 직전 점검 체크리스트**(요약집 한 줄 요약이 붙은 `- [ ]` 목록)
  → 과목·단원별로 묶인 문항 전체
- **문항마다** — 지문의 표·코드·그림을 마크다운으로 그대로 옮기고,
  보기에 `← 내가 고른 답` / `**← 정답**` 표시, 내가 남긴 메모와
  "모르겠다고 적은 것"까지 함께 담습니다

이 사이트의 특징인 **선택지 기반 오개념 분석**이 문항마다 한 줄로 붙습니다.

```md
- 내 답 **①** → 정답 **③**
- 내가 고른 선택지는 「프로토타입」 개념입니다
- 정답 선택지는 「싱글톤」 개념입니다
```

고른 것과 정답이 **같은 개념**이면 개념을 헷갈린 게 아니라 세부를 놓친 것이므로,
그렇게 한 줄로 바꿔 적습니다.

`⤓ 마크다운 내려받기`(`최종_오답노트_YYYY-MM-DD.md`)와 클립보드 복사를 지원합니다.
그림은 `img/` 상대 경로로 걸리므로 사이트 폴더 안에 두고 열면 함께 보입니다.

## 화면 — 실기

실기는 **주관식 필답형**이라 선택지가 없습니다. 답을 직접 입력하면 채점합니다.

### 1. 홈
푼 문제 수·정답률·진도, 안 푼 문제 / 틀린 문제 / 랜덤 바로 풀기, 유형별 현황,
약한 개념 랭킹, 자주 나온 실수(off-by-one·서식 차이 등) 집계.

### 2. 회차별
12회차 카드에서 회차별 진도와 정답률을 보고 이어풀기. 2025년 1회는 11~19번이
복원되지 않아 11문항만 수록되어 있고, 카드에 그 사실이 표시됩니다.

### 3. 유형별
| 기준 | 갈래 |
|---|---|
| 유형 | 코드 출력 77 · 단답형 69 · 괄호 채우기 60 · SQL 작성 19 · 순서 나열 6 |
| 언어 | C 44 · Java 25 · SQL 19 · Python 9 |
| 개념 | 네트워크 53 · 데이터베이스 32 · SQL 26 · 애플리케이션 테스트 21 · 포인터 14 … |

### 4. 학습노트 (33개)
231문항을 분석해 **실제로 반복 출제되는 것만** 정리했습니다.
프로그래밍 15개(반복문·포인터·값과 참조·객체지향·파이썬 등) + 이론 18개(OSI·포트·서브넷·정규화·SQL·테스트·스케줄링 등).
각 노트는 `핵심 규칙` + `자주 틀리는 지점` + **그 개념이 실제로 나온 기출 목록**으로 구성되고,
노트에서 바로 해당 기출 묶음을 풀 수 있습니다. 문제 화면에서도 관련 노트로 역방향 링크가 걸립니다.

### 5. 오답노트
틀린 문제를 **개념별 / 회차별 / 실수 유형별**로 묶어 봅니다. 마크다운 복사 지원.

### 6. 취약점 분석 · AI 학습
정적 사이트라 API 키를 넣을 수 없어, 필기 쪽과 같은 **복사–붙여넣기 왕복**으로 처리합니다.
프롬프트를 복사해 Claude·ChatGPT에 붙여넣으면 `.json` 파일을 만들어 주고, 그 파일을 올리면 됩니다.

| 탭 | 하는 일 |
|---|---|
| 취약점 분석 | 내 오답에서 **개념별 / 유형별 / 언어별 정답률**과 채점기가 분류한 **실수 패턴**을 뽑아 보여줍니다 |
| 개념 요약 | 위 진단 + 내가 틀린 문제 원문(코드·내 답·정답 포함)을 담은 프롬프트 → `prac-notes.json` |
| 유사문제 | 같은 개념을 다른 숫자·변수로 묻는 주관식 문제 → `prac-drill.json` |

개념 요약 노트에는 `내가 틀린 지점`(내 실제 오답을 인용한 진단)과 `근거가 된 내 오답` 링크가 붙어,
노트에서 그 기출로 바로 넘어갈 수 있습니다.

생성된 유사문제는 **기출과 똑같은 카드·채점기**로 풀립니다. 다만 답안 기록은 따로 저장해
기출 정답률과 취약 개념 통계를 흐리지 않습니다.

## 실기 채점 방식

주관식이므로 단계적으로 완화해서 비교합니다.

| 단계 | 판정 |
|---|---|
| 1 | 줄바꿈·공백까지 완전 일치 → 정답 |
| 2 | 공백·개행만 다름 → 정답 (코드 문제는 "서식 차이" 안내) |
| 3 | 괄호·기호·대소문자 무시하고 일치 → 정답 |
| 4 | (코드 외) 정답 문자열을 포함 → 정답 |
| 5 | `① … ② …` 형태의 여러 칸 답은 칸별로 세어 **부분 정답** 표시 |
| 6 | 코드 문제 오답은 원인을 진단 (1 차이 / 부호 반대 / 자릿수 밀림 / 출력 줄 수 / 출력 순서 …) |

비교 전에 양쪽 답을 같은 규칙으로 정규화하므로 **키보드로 칠 수 있는 문자만으로 입력해도 정답**이 됩니다.

- `①②③` 칸 번호는 빼고 값만 순서대로 써도 되고, `1.` `1)` 처럼 써도 됩니다
- 보기 기호는 데이터에서 전부 `ㄱ ㄴ ㄷ ㄹ …`로 통일했습니다 (`㉠` `ⓐ` 없음)
- 구분자는 쉼표·공백·줄바꿈·`->` 무엇이든 됩니다
- 대소문자와 괄호·마침표는 무시합니다

문제마다 **입력 형식 안내**가 답안 칸 위에 표시됩니다 (몇 개를 어떤 구분자로 쓸지, 줄바꿈을 맞춰야 하는지).

`alt` 필드에 동등하게 인정되는 표기를 함께 넣어 두었습니다
(예: 외래키 = FK = Foreign Key, 데이터 링크 계층 = 2계층).

> 231문항 전부에 대해 "정답 원문과 `alt` 전부가 정답 처리되고, 엉뚱한 답은 정답 처리되지 않는지"를 자동 검증했습니다.

## 오답 분석이 동작하는 방식

빌드 단계에서 **모든 선택지 하나하나에** 관련 요약 항목을 붙여 뒀습니다 (`options[].refs`).

```json
{
  "no": 8, "answer": 1, "refs": [54, 52, 53],
  "options": [
    {"no": 1, "text": "하나의 객체를 생성하면 …", "refs": [54, 47]},
    {"no": 2, "text": "원본 객체를 복제하는 …",   "refs": [53]},
    {"no": 3, "text": "여러 객체를 가진 복합 …",  "refs": [55]},
    {"no": 4, "text": "수많은 객체들 간의 …",     "refs": [52]}
  ]
}
```

문제를 틀리면 이렇게 점수가 쌓입니다.

| 신호 | 의미 | 가중치 |
|---|---|---|
| 내가 고른 오답의 `refs` | 이 개념을 **옳다고 착각**했다 | **+3** |
| 정답 선택지의 `refs` | 이 개념을 **몰랐다** | +2 |
| 문항 주제 `refs[0]` | 이 주제가 약하다 | +2 |
| 정답을 맞힌 문항의 `refs` | 회복 | −1 |
| "모르겠음" 누름 | 주제 전체가 약함 | +2 |

예를 들어 싱글톤 문제에서 ②(프로토타입 설명)를 고르면
→ *"053 생성 패턴 - 프로토타입"* 에 +3, *"054 싱글톤"* 에 +2가 쌓입니다.
즉 **"싱글톤을 몰라서"가 아니라 "프로토타입과 싱글톤을 헷갈려서" 틀렸다**는 게 기록됩니다.

오답분석 화면의 「선택지로 본 오개념」은 이 기록을 개념별로 묶어서 보여줍니다.

## 문제 생성

**A. 기출 재출제** — 취약 점수 상위 12개 개념과 연결된 기출을, 미풀이 > 틀림 > 맞힘 순으로 정렬해 출제

**B. 요약집 기반 자동 생성** (완전 오프라인, 클라이언트에서 생성)
- `notin` — "다음 중 「XXX」에 해당하지 않는 것은?" : 해당 항목 불릿 3개 + 다른 항목 불릿 1개
- `define` — "다음 설명에 해당하는 것은?" : 용어 정의 → 용어 맞히기
- `match` — "「XXX」에 대한 설명으로 옳은 것은?" : 용어 → 정의 맞히기

오답 보기는 **같은 단원**에서 우선 뽑아 난이도를 맞추고, 정답 보기와 머리말이 겹치면 제외해 모호한 문제를 방지합니다. 예제 풀이 과정·숫자 나열 불릿은 재료에서 제외합니다.
(생성 600문항 자동 검증: 보기 4개·중복 없음·정답 범위 이상 0건)

**C. AI 연동** — 「프롬프트 복사」를 누르면 내 취약 개념 + 메모 + 최근 오답이 담긴 프롬프트가 복사됩니다.
Claude/ChatGPT에 붙여넣고 받은 JSON을 「생성 JSON 불러오기」로 그대로 풀 수 있습니다.

```json
[{"q":"문제 지문","code":"코드/표(선택)","options":["…","…","…","…"],
  "answer":2,"why":"해설","misread":["①을 고른 이유","②…","③…","④…"],"topic":"개념명"}]
```

## 데이터 저장

모든 학습 기록은 브라우저 `localStorage`(키 `jbsg_v2`)에만 저장됩니다.

```js
{ answers:{qid:{sel,ok,t,exam,no,sub,unit}},  // [필기] 문항별 응답
  weak:{secNo: score},                        // [필기] 취약 개념 점수
  notes:{qid: "메모"}, secNotes:{secNo: "메모"},
  secRead:{secNo:1}, gen:[…], unknown:[qid],
  mock:{t, items:[{src,qid|id,sec}], ans:{idx:pick}, i},  // [필기] 모의고사 세트
  gaps:{qid: "내가 모르겠다고 적은 것"},        // [필기] 최종 오답노트에 함께 실림
  prac:{                                      // [실기]
    ans:{qid:{ok,v,t,type,exam,pat,part,tags}},  // 내가 쓴 답 + 오답 원인
    tag:{개념: score},                            // 개념별 약점 점수
    read:{noteId:1},                              // 학습노트 완료 표시
    aiNote:{개념:{concept,memorize,compare,myMistake,drill,qids}},  // AI 개념 요약
    aiQ:[{id,type,lang,q,code,a,alt,why,tags}],   // AI 유사문제
    aiAns:{qid:{ok,v,t,pat}} } }                  // 유사문제 답안 (기출과 분리)
```

기기를 옮기거나 초기화하기 전에 **⚙ → 백업 내보내기**로 JSON을 저장하세요.

## 로딩 속도

| 구간 | 크기 | 시간 |
|---|---|---|
| 초기 전송 (index.html + index.json + summary.json) | 143KB → **gzip 49KB** | — |
| JS 부팅(파싱 + 첫 화면) | | **20ms** |
| 화면 렌더 (가장 무거운 요약 193항목) | | 22ms |

- `glossary.json`은 용어사전·문제생성 탭에 들어갈 때만 받습니다.
- 실기 데이터(`prac-*.json`, 합계 약 210KB)는 **실기 모드에 들어갈 때 한 번만** 받습니다. 필기만 쓰는 동안에는 전송되지 않습니다.
- 회차 데이터는 첫 화면을 그린 뒤 `requestIdleCallback`으로 미리 받아 둡니다.
- `sw.js`(서비스 워커)가 캐시하므로 **두 번째 방문부터는 네트워크 없이 즉시** 뜨고, 오프라인에서도 동작합니다.
- 데이터를 바꾸면 `sw.js`의 `const V` 값을 올려 주세요(현재 `jbsg-v7`). 안 그러면 옛 캐시가 남습니다.
- `manifest.webmanifest`가 있어 모바일에서 "홈 화면에 추가"하면 앱처럼 실행됩니다.

## 확장

- **구 체계 기출 추가** — `data/exam-YYYY-N.json`을 같은 스키마로 추가하고 `data/index.json`의 `exams` 배열에 항목을 넣으면 됩니다.
- **단원 재정의** — `data/index.json`의 `units`(과목·이름·요약항목 범위)만 고치면 전 화면에 반영됩니다.
- **해설 추가** — 2024년 PDF에는 해설이 있습니다. 문항 JSON에 `"explain": "…"` 필드를 넣고 `fbHtml()`에서 출력하도록 한 줄 추가하면 됩니다.
- **실기 회차 추가** — `build/raw/<회차>.json`을 같은 스키마로 추가하고 `build/build_prac.py`의 `ORDER`에 회차 id를 넣은 뒤 다시 실행하면 `prac-exam.json`·`prac-index.json`이 갱신됩니다. 이 스크립트는 학습노트의 `qids`가 실제 문항을 가리키는지도 함께 검사합니다.

```bash
python build/build_prac.py data
```
